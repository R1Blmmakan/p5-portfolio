# DESIGN.md: Persona 5 Manga Dossier Design Direction

## System Identity & Design Read
> **Reading this as:** Interactive web developer portfolio for technical recruiters and high-caliber engineering leads, in an authentic Persona 5 / Manga Classified Dossier style, dial **ENERGY 3 / RHYTHM 3 / MOTION 2**.

## Three Dials
- **ENERGY 3 (Bold)**: High-voltage JRPG rebellion, bold contrast, angled comic frames, and classified dossier tape pins. No timid, washed-out neutrals.
- **RHYTHM 3 (Asymmetric)**: Varied manga panels, diagonal cut-outs, dynamic metadata telemetry tags, and distinct acts (Act 01: Origin, Act 02: Arsenal, Act 03: Battle Record).
- **MOTION 2 (Kinetic with Restraint)**: Hardware-accelerated entrance transitions, 60fps GPU hover lifts, and zero endless/looping idle animations. All motion has explicit user-trigger purpose.

## Visual Vocabulary & Tokens

### Palette (R-29 Compliant)
- **Base Neutral**: `#000000` (Pitch Black), `#040508` (Dark Stage Backdrop)
- **Primary Signal**: `#e60012` (Persona Crimson Red): Used for primary callouts, title slashes, and critical status.
- **Structural White**: `#ffffff` (High-contrast manga panel borders and typographic punch)
- **Accents (Disciplined Dose Cap)**:
  - `#ffea00` (Hazard Gold): Used exclusively for certifications, honors, and hazard warning tape.
  - `#00e1ff` (Persona 3 Cyan): Reserved for system navigation and loader states.

### Typography (R-06 Compliant)
- **Display & Titles**: `'Anton', sans-serif`: Heavy condensed italic display for manga impact.
- **Telemetry, Code & Data**: `'Space Grotesk', monospace`: Precision tabular tracking and high-readability metadata.
- **Brand Glyphs**: `'Persona5'` custom TTF for JRPG iconography and menu emblems.

### Design Levers
1. **One Focal Point Per Screen**: The candidate's verified identity dossier and action pipeline anchor the layout; story panels expand to the right.
2. **Hierarchical Contrast**: Extreme size scales (large italic display headers vs crisp compact metadata labels).
3. **Intentional Surfaces**: Hard-edged manga paper, halftone dot screentones, and hazard tape pins replace generic blurred glassmorphism.
